# Globiim Backend

Laravel API backend for Globiim. The first module is Account & Authentication. Messaging, Meetings, Workspace and Groups are intentionally out of scope for this phase.

## Planned stack
- Laravel PHP API
- MySQL database
- Laravel Sanctum token authentication
- OTP verification through a configurable delivery provider

## Account module
- Email or phone registration
- Login/logout
- Individual, Creator, Business and Manufacturer account types
- Profile management
- Password reset
- Email/phone verification

Implementation and deployment status will be documented as the module is built and tested.
